## カレンダー（2026-10-28）

提示した選択肢と結果:

| 項目 | 選んだもの | 選ばなかったもの |
|---|---|---|
| 載せる情報（複数選択） | 食品の期限日 / タスクのリマインド / 日ごとの支出額 | 日記・服薬の記録（MedCal の GAS の追加と再デプロイが必要。後から足せる） |
| 見せ方 | 週表示 | 月グリッド＋日をタップで詳細（推奨案だった）/ 今日から 2 週間のリスト |
| 置き場所 | ホームのカードの 1 つ | ホームのタブで切り替え / 別画面（アイコンで開く） |

- 週表示は、上段に 7 日の列（日付と種類ごとの印・支出額）、下段にタップした日の詳細。スマホでは 1 日の列が細いので、詳細は列の中ではなく下に出す
- 日曜始まり（MedCal に揃えた）。‹ › で週を移動、「今週」で戻る
- 支出の日別合計だけ Home 用 GAS に `daily` を追加した（GAS 1.2.0）。他の情報は既存の API で足りる
- 色の約束: 赤・橙・緑は食品の期限（Food Inv. Manager と同じ）、青はタスクのリマインド
